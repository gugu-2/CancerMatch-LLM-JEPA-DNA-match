# PathoMatch API Reference

The FastAPI backend exposes endpoints for uploading genomic samples and retrieving AI-generated clinical insights.

## Base URL
`http://localhost:8000`

---

## 1. Health Check
Verify the API is running and responsive.

**Endpoint:** `/health`
**Method:** `GET`

**Success Response:**
```json
{
    "status": "ok"
}
```

---

## 2. Sample Upload & Analysis
Uploads a patient's genomic sequence metadata and triggers the AI LangChain RAG pipeline to generate a species-specific clinical report.

**Endpoint:** `/api/upload`
**Method:** `POST`
**Headers:** `Content-Type: application/json`

### Request Body (JSON)
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `species` | `string` | **Yes** | The host species (e.g., "Human", "Canine", "Bovine"). **Crucial for RAG metadata filtering.** |
| `priorAntibiotics` | `boolean` | **Yes** | Whether the patient has recently received antibiotics. |
| `notes` | `string` | No | Free-text clinical notes, symptoms, or patient history. |
| `fileName` | `string` | No | The name of the FASTA/FASTQ sequence file being analyzed. |

**Example Request:**
```json
{
    "species": "Canine",
    "priorAntibiotics": true,
    "notes": "Suspected septic peritonitis following abdominal surgery.",
    "fileName": "patient_123_sample.fasta"
}
```

### Response
The response contains the status and the generated `ai_report`, which includes the exact guidelines retrieved from the vector database.

**Success Response (200 OK):**
```json
{
    "status": "success",
    "message": "Clinical report generated for Canine",
    "data_received": {
        "species": "Canine",
        "priorAntibiotics": true,
        "notes": "Suspected septic peritonitis following abdominal surgery.",
        "fileName": "patient_123_sample.fasta"
    },
    "ai_report": {
        "retrieved_documents": [
            "In canine septic peritonitis, immediate surgical source control and IV enrofloxacin + ampicillin/sulbactam is recommended.",
            "Canine isolates showing resistance to cephalexin should be treated with clindamycin."
        ],
        "llm_prompt": "You are an expert PathoMatch AI Clinical Assistant specializing in canine medicine...",
        "llm_response": "Based on the retrieved clinical guidelines, here is the recommended treatment protocol...\n\n(This is a mock LLM response generated by FakeListLLM)"
    }
}
```

### Error Responses
**422 Unprocessable Entity:**
Returned if the request body is missing required fields (like `species`).
```json
{
    "detail": [
        {
            "type": "missing",
            "loc": ["body", "species"],
            "msg": "Field required",
            "input": {}
        }
    ]
}
```
